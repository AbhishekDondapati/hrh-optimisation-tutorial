# Prescriptive optimisation for health workforce allocation

Code and simulated data for the paper:

> Dondapati, A. (2026). *Beyond the staffing gap: an integer optimisation framework for health workforce allocation in Indian public health systems.* 

The repository turns a norm-based staffing gap (here, against the Indian Public Health Standards 2022) into decisions, using six linked models:

| Paper section | Model | File |
|---|---|---|
| 3.1 | Inequality diagnostics: required-post-weighted Gini and Theil-T with exact between/within decomposition | `src/diagnostics.py` |
| 3.2 | Capability test: is every referral specialty (OBG, anaesthesia, paediatrics) in post? | `src/diagnostics.py` |
| 4.1 | Redeployment of surplus specialists as an integer transportation problem, within a transfer unit | `src/redeploy.py` |
| 4.2 | Budget-constrained allocation of new posts with diminishing returns | `src/allocate.py` |
| 4.3 | Equity-impact frontier (epsilon-constraint, solved exactly as a 0-1 knapsack) | `src/allocate.py` |
| 4.4 | Phased recruitment with capacity limits and attrition | `src/allocate.py` |
| 5.5 | Monte Carlo robustness of recruitment timelines (500 replications) | `src/robustness.py` |

All integer programmes are solved with the open-source CBC solver through PuLP.

## Quick start

Requires Python 3.10 or later.

```bash
git clone https://github.com/AbhishekDondapati/hrh-optimisation-tutorial.git
cd hrh-optimisation-tutorial
pip install -r requirements.txt
python src/run_all.py          # main results, about 10 seconds
python src/run_all.py --sens   # also the sensitivity analyses of Appendix A
python src/robustness.py       # Monte Carlo robustness of recruitment timelines (Section 5.5)
```

The script prints Tables 3-5 of the paper and writes:

- `results/results.json`: every number reported in Section 5 and Appendix A
- `results/zone_moves.csv`: the transfer list from zone-bound redeployment
- `results/phased_recruitment.csv`: year-by-year coverage, hires, posts to create and wage bill

Expected headline results:

| Result | Value |
|---|---|
| Gap (doctors / nurses / paramedics) | 1,831 / 9,469 / 3,774 posts |
| Zone-bound redeployment | 228 moves; all 44 referral-specialist gaps closed |
| District-bound redeployment | 198 moves (87% of the network-wide optimum) |
| Full-gap wage cost after redeployment | Rs 1,007.5 crore a year |
| Facilities functional at a 30% floor (25% budget) | 100 of 140 (121 with no floor) |
| Year nurses reach the norm (base / high capacity) | 14 / 6 |

## Data

The `data/` folder holds a **simulated** network of 140 secondary-care facilities (122 existing, 18 new) in 26 districts and 6 transfer zones. Staffing levels and the specialist roster were generated by stratified bootstrap from the distributions observed in a real state network, with random perturbation, so the patterns are realistic but no record corresponds to a real facility. Appendix B of the paper describes the procedure and compares the simulated and source networks.

| File | One row per | Columns |
|---|---|---|
| `facilities.csv` | facility | `fid`, `facility`, `district`, `zone`, `multizone`, `tier`, `status` (Existing/New), `beds`, `D_req`, `N_req`, `P_req` (IPHS-2022 requirement), `D_act`, `N_act`, `P_act` (staff in post) |
| `roster.csv` | facility x department of the specialist norm (facilities with a roster) | `fid`, `dept`, `desig`, `req` (specialist norm), `cat` (norm category), `avail` (specialists in post) |
| `misplaced.csv` | specialist posted to a department outside the facility's norm | `fid`, `dept`, `desig`, `avail` |
| `specialist_norms.csv` | norm category x department | `cat`, `dept`, `desig`, `req` |

D = doctors, N = staff nurses, P = paramedics.

## Using your own data

Replace the four files in `data/` with your own, keeping the same columns, and edit `src/config.py` for:

- cost per post (`BASIC_PAY`, `GROSS_UP`)
- priority weights for redeployment (`PRIORITY`)
- recruitment capacity scenarios (`CAPACITY`), attrition and planning horizon
- sanctioned posts (`SANCTIONED`)

The models work for any tier of the system (sub-centres, PHCs, CHCs, district hospitals) once the norm table and cadres are changed.
